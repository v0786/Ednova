# EDNOVA Mobile Screen Mapping Specification

## 1. Principal Mobile App (`Role: PRINCIPAL`)
- **Primary Screen**: Institutional Executive Desk (`/mobile` Principal View).
- **Core Modules**:
  - Daily Attendance Overview Card (96.4% aggregate)
  - Pending Approvals List
  - Active Safety Incident Timeline #41
  - AI Gateway Assistant Console ("Ask EDNOVA AI")

## 2. Staff / Teacher Mobile App (`Role: TEACHER`, `Role: ADMIN_STAFF`)
- **Primary Screen**: Roster & Notes Console (`/mobile` Teacher View).
- **Core Modules**:
  - Class Schedule & Room Indicators
  - One-tap Roster Attendance Entry (`☑ All Present`, `✓` / `✕` toggles)
  - Class Test Mark Entry
  - Today's Notes Publisher

## 3. Student Mobile App (`Role: STUDENT`)
- **Primary Screen**: Student Academic Workspace (`/mobile` Student View).
- **Core Modules**:
  - Today's Class Schedule (Time + Subject + Room Number)
  - Test Marks & Letter Grades Summary
  - Announcements Feed
  - Confidential Feedback Submission

## 4. Parent Mobile App (`Role: PARENT`)
- **Primary Screen**: Linked Child Guardian Desk (`/mobile` Parent View).
- **Core Modules**:
  - Linked Child Selector (Strict DB linkage validation)
  - Real-Time Gate Entry Push Notifications
  - Child Academic Report Cards & Attendance Logs
